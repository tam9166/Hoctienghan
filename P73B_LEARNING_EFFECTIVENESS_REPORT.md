# P73B LEARNING EFFECTIVENESS REPORT

## 1. Vietnamese advantage

The Vietnamese-first assistant covers six controlled problem groups: `ㅓ/ㅗ`, `ㅡ`, `ㄹ`, `은/는` versus `이/가`, `을/를`, and clothing verbs such as `입다/쓰다/신다`. Existing Error Notebook and pronunciation attempts can promote a topic to personal priority; absent evidence, the authored curriculum order is used.

## 2. Word Life

Word Life presents meaning, example, related words, common mistake, grammar pattern, real conversational form and a clear “when do I use this?” situation. Entries connect to the existing Dictionary and SRS instead of creating a second vocabulary scheduler.

## 3. Diagnostic

Learning Health Report bridges the existing P71A diagnostic. It exposes Vocabulary, Grammar, Listening, Speaking, Reading and Writing with evidence coverage, strengths, weaknesses and the weakest skill. Missing evidence remains blank and is never converted into a fabricated score.

## 4. Learning plan

A 14-day improvement plan is built from the current weakest skill. It contains three concrete phases covering Days 1–5, 6–10 and 11–14 and routes into existing practice modules. The underlying P71A prescription is also recorded so Adaptive/Learner Memory continues to see the same decision.

## 5. Listening journey

The listening presentation progresses through sound, word, sentence, dialogue and natural speed. Availability is based on existing pronunciation, listening, shadowing and listening-active-recall evidence rather than a separate mastery score.

## 6. Course structure

`Korean Beginner Zero → TOPIK 1` packages existing curriculum into four Chapters with lessons and checkpoints. Certificate eligibility requires a real Foundation checkpoint, completed lessons and Active Recall accuracy. XP is explicitly excluded from certification evidence.
